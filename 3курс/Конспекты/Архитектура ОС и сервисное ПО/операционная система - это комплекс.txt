операционная система - это комплекс программ, который управляет ресурсами компьютера, абстрагирует железо и предоставляет пользователю интерфейс для работы.

Абстрагирует железо - создаёт и разграничивает уровни доступа человека до аппаратной части.

Главные функции ОС:
1) Управление ресурсами:
(
CPU - какой процесс получит процессор и на сколько, 
Память - кому и сколько выгрузить кэш,
Диск - кто и когда читает и пишет данные,
Устройства ввода вывода, сеть и подключение -   
)

2) Абстракция железа 
(
пользователь работает с файлами а не с диском.
пользователь работает с процессами, а не с регистрами CPU.
приложение открывает сокет для передачи данных, а не обращается напрямую к сетевой карте
)



Интерфейсы:
CLI - bash, powershell, cmd
GUI - проводник, рабочий стол
API - системные вызовы для программистов
