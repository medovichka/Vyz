Вопросы:

1. Зачем планировщики
    Ответ: Для обеспечения всех процессов ресурсами
    Следить за предоставлением ресурсов
    Порядок выполнения процессов
    Порядок выделения ресурсов
    И это всё оптимально.

2. Выделение памяти процессов
есть 3 алгоса, все алгосы работают одинаково, в чём суть, чем отличаются те которые мы изучали.

    Ответ: выбирается первый своб. участок памяти куда помещается процесс, независимо от алгоса,
    отличие в сортировке свободных участков памяти.
    Первый Fit — по адресу,
    Наиболее Fit — по возрастанию размера,
    Наименее Fit — по убыванию размера.

3. Что такое вытесняющее \ невытесняющее, какие алгоритмы есть для каждого
Вытесняющая многозад - ОС упр время выполннеия на процессоре

Вытесняющие - ОС может принудительно снять процесс с процессора.
    SJN
    SRT
    FCFS
Невытесняющие - Процесс, получивший CPU, работает до тех пор, пока сам не отдаст процессор.
    Round Robin
    Unix
    ОС2
    Windows NT

4. Алгоритм RR, программы всё время запускаются снимаются, какую задачу надо решить перед RR?
    Ответ: Сохранение контекста
    самамя большая проблема - выбор кванта времени
    Кончился квант
    Сохраняется контекст
    Переходит к дургому сегмунту состояния задачи
    (накладные расходы)

5. какие алгоритмы планирования используются в windows?
    Ответ:
    Смешанные - RR,FCFS
    Многоуровневое приоритетное распределение

6. Отличие unix и windows алгоритмов - Ответ: абсолютный динамический приоритет
UNIX (в классических реализациях, таких как BSD) использует динамическое планирование.
Планировщик наказывает процессы, активно использующие CPU, понижая их приоритет, и поощряет интерактивные процессы, повышая их приоритет.
абсолютный динамический приоритет - вытеснение + изменение приоритета

7. Недостатки и плюсы FCFS
    Плюсы: простой понятный, нет динамики
    Недостатки: Процессы встают в очередь по поступлению, нет приоритезации.
