Управление задачами в ОС

Термин задача в операционных системах используется в качестве синонима к слову процесс.
Процесс - это абстракция, описывающая выполняющую программу.

Для ОС процесс представляет собой единицу работы, заявку на потребление системных ресурсов.

2) По цели
