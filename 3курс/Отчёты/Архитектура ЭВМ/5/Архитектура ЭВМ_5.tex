\section*{Цель}
\addcontentsline{toc}{section}{Цель}
Объединить и исследовать совместную работу операционного устройства  и устройства управления  микропрограммируемого микропроцессора при взаимодействии с оперативным запоминающим устройством и постоянным запоминающим устройством начальных адресов .

\section*{Задание}
\addcontentsline{toc}{section}{Задание}
Выполнить сдвиг 8-разрядного двоичного кода $X$ на $N$ разрядов в сторону старших разрядов (сдвиг логический). Исходные данные ($КОП$, $X$, $N$) считываются из ОЗУ, переход к операционному блоку осуществляется по коду операции через таблицу ПНА, а полученный результат $Z$ записывается обратно в ОЗУ.

На рис.1 показано распределение памяти данных и памяти начальных адресов.
\begin{figure}[H]
	\centering
	\includegraphics[width=0.95\textwidth]{ОЗУ.png}
	\caption{Содержимое вкладки «ОЗУ, ПНА и ПА»}
	\label{fig:mem}
\end{figure}

\textbf{Распределение памяти ОЗУ:}

\begin{itemize}
	\item\textbf{Ячейка 00:} значение `0000` — код операции (КОП), обеспечивает выбор ячейки 00 в ПНА.
	\item\textbf{Ячейка 01:} значение `0022` — сдвигаемое двоичное число (X).
	\item\textbf{Ячейка 02:} значение `0001` — количество разрядов сдвига (N).
	\item\textbf{Ячейка 03:} значение `0000` — ячейка для записи результата сдвига (Z).
\end{itemize}
\textbf{Распределение памяти ПНА:}
\begin{itemize}
	\item \textbf{Ячейка 00:} значение `0A` — начальный адрес микропрограммы сдвига (МК 0A).

\end{itemize}

\section*{Кодирование микропрограммы}
\addcontentsline{toc}{section}{Кодирование микропрограммы}
В табл. 2 приведено кодирование микропрограммы для совмещённого микропроцессора (в шестнадцатеричной системе счисления).

Микропрограмма разделена на три логических блока:
\begin{enumerate}
	\item \textbf{Блок чтения исходных данных (МК 00 - МК 04):} регистр $RF$ используется как указатель адреса ОЗУ. В МК 00 регистр $RF$ обнуляется (код АЛУ $343$). Команда $303$ при $C_0 = 1$ и $\text{\textasciicircum OE} = 0$ увеличивает $RF$ на единицу и одновременно загружает новый адрес в регистр адреса ОЗУ ($\text{\textasciicircum CS}=1, \text{\textasciicircum W}=1, \text{\textasciicircum EA}=0$). Команда $337$ при режиме чтения ОЗУ ($\text{\textasciicircum CS}=0, \text{\textasciicircum W}=1, \text{\textasciicircum EA}=1$) и отключённом выходе АЛУ ($\text{\textasciicircum OE}=1$) считывает операнды с шины данных: число $X$ из ячейки $01$ загружается в регистр $R0$, а число сдвигов $N$ из ячейки $02$ — в регистр-счётчик $R9$.
	\item \textbf{Блок дешифрации КОП и записи результата (МК 05 - МК 08):} в МК 05 адрес ОЗУ сбрасывается в ноль ($RA := 0$, код $143$), при этом значение указателя $RF = 2$ сохраняется. В МК 06 считывается $КОП$ из ячейки $00$ ОЗУ и выполняется микроинструкция JMAP ($\text{I3-0} = 2$), осуществляющая переход по адресу из таблицы ПНА (на МК 0A). После завершения сдвигов управление возвращается на МК 07, где адрес в $RF$ увеличивается до $03$, и в МК 08 результат из $R0$ записывается в ячейку $03$ ОЗУ ($\text{\textasciicircum CS}=0, \text{\textasciicircum W}=0, \text{\textasciicircum EA}=1$), после чего микроинструкция JZ ($\text{I3-0} = 0$) завершает цикл.
	\item \textbf{Операционный блок сдвига (МК 0A - МК 0C):} в МК 0A проверяется условие $R9 = 0$ (код $133$). При $Z = 1$ ($U = 1, \text{\textasciicircum CCE} = 0$) микроинструкция CJP ($\text{I3-0} = 3$) выполняет переход на МК 07 для записи ответа. Если $Z = 0$, в МК 0B выполняется логический сдвиг $R0$ влево ($\text{I8-0} = 733, \text{SC} = 00$), а в МК 0C счётчик $R9$ уменьшается на единицу ($\text{I8-0} = 313$) с безусловным возвратом ($\text{\textasciicircum CCE} = 1$) на проверку в МК 0A.
\end{enumerate}

\section*{Пример}
\addcontentsline{toc}{section}{Пример}
В качестве первого примера рассмотрим выполнение микропрограммы при исходных данных $X = 0022_{16}$ ($0000\,0000\,0010\,0010_2$) и $N = 0001_{16}$.

В микрокомандах МК 00 - МК 04 процессор последовательно инкрементирует указатель адреса $RF$ и считывает из ОЗУ операнды: в регистр $R0$ загружается число $X = 0022_{16}$, а в регистр $R9$ — число сдвигов $N = 0001_{16}$ (при этом указатель $RF$ останавливается на значении $2$). В МК 05 регистр адреса ОЗУ сбрасывается в $00$, и в МК 06 выполняется микроинструкция JMAP (код МИ $2$). Так как в ячейке $00$ ОЗУ записан $КОП = 0000_{16}$, адрес перехода считывается из нулевой ячейки ПНА ($0A$), и управление передаётся на МК 0A.

На рис.2 показано выполнение перехода по коду операции в микрокоманде МК 06.
\begin{figure}[H]
	\centering
	\includegraphics[width=0.8\textwidth]{переходЬК6.png}
	\caption{Переход по КОП через ПНА в микрокоманде МК 06}
	\label{fig:mk06_jmap}
\end{figure}

В МК 0A проверяется содержимое счётчика $R9$. Поскольку $R9 = 1 \neq 0$, формируется признак $Z = 0$, условие перехода на выход ($Z = 1$) не выполняется, и управление передаётся МК 0B. В МК 0B число $X$ в регистре $R0$ логически сдвигается влево на один разряд, превращаясь в $0044_{16}$ ($0000\,0000\,0100\,0100_2$). В МК 0C из счётчика $R9$ вычитается единица ($R9 = 0$), после чего происходит безусловный переход обратно на МК 0A.

При повторной проверке в МК 0A счётчик равен нулю ($Z = 1$), условие срабатывает, и микроинструкция CJP осуществляет переход на адрес $007$. В МК 07 адрес ОЗУ формируется как $RF + 1 = 3$, а в МК 08 полученный результат $0044_{16}$ из регистра $R0$ записывается в ячейку $03$ ОЗУ .

На рис.3 показано итоговое состояние регистров и ячейки результата $Z$ в ОЗУ после завершения работы программы.
\begin{figure}[H]
	\centering
	\includegraphics[width=0.8\textwidth]{записьZ.png}
	\caption{Запись результата сдвига $Z = 0044_{16}$ в ячейку 03 ОЗУ}
	\label{fig:result_z}
\end{figure}

В качестве второго примера рассмотрим изменение кода операции ($КОП$) для чтения начального адреса микропрограммы из первой ячейки таблицы ПНА ($\text{ПНА}[01] = 0A$). Поскольку младшие 8 разрядов (биты $0..7$) при переходе JMAP не адресуют ПНА, для обращения к ячейке $01$ ПНА необходимо установить единицу в 9-й разряд справа (бит 8) ячейки $00$ ОЗУ, что соответствует коду $0000\,0001\,0000\,0000_2$ ($0100_{16}$ или $000400_8$). При запуске микропрограммы в МК 06 процессор считывает изменённый $КОП$, обращается к ячейке $01$ ПНА и корректно переходит к операционному блоку на МК 0A.

\section*{Вывод}
\addcontentsline{toc}{section}{Вывод}
В ходе лабораторной работы было выполнено объединение операционного устройства и устройства управления микропрограммируемого микропроцессора для реализации алгоритма логического сдвига двоичного числа $X$ на $N$ разрядов влево.

Была разработана микропрограмма, обеспечивающая последовательное чтение исходных данных из ОЗУ с использованием индексного регистра-указателя $RF$, дешифрацию кода операции через таблицу начальных адресов ПНА (микроинструкция JMAP), циклическое выполнение сдвига с контролем счётчика по признаку нуля $Z$ (микроинструкция CJP) и сохранение результата обратно в ОЗУ.

Экспериментальная проверка подтвердила правильность вычислений, отсутствие конфликтов на внутренней шине адреса данных и корректную адресацию таблицы ПНА при изменении кода операции.
