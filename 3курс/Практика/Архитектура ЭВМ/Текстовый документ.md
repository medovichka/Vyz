В модели Excel каждый аппаратный узел схемы представлен отдельной ячейкой, логика работы естестенно описана формулами. Для наглядности ключевым ячейкам присвоены собственные имена. Архитектура стека разделена на пять функциональных зон:

**1. Блок управления и входы команд**

* **Управляющие входы (B9, C9, D9):** ячейки отвечающие за команды ЗП (запись), ЧТ (чтение) и НУ (начальная установка).
* **Блок управления БУ (C3):** задаёт такты операции переключаясь между 1 и 0 при пересчете листа.

**2. Вход данных и регистр-счётчик (сверху)**

* **Вход данных Д (H2):** поле для ввода 8-битного числа.
* **Переключатель ВД (J4):** задает режим ввода данных.
* **Регистр-счётчик данных РСД (H4):** при записи подает числа на вход стека (если ВД равен 1, автоматически увеличивает предыдущее число на единицу после каждой записи), а при чтении — принимает значение, вышедшее из вершины стека.

**3. Блок регистров памяти БР (в центре, H6–H13)**

* **Вершина стека (GH6):** R0 -  первые ступени регистров БР. r0 - вторые ступени регистров БР.
* **Остальные ячейки (GH7–GH13):** G - вторые ступени регистров БР r1–r7 и H: для первых ступеней регистров R1–R7.

**4. Признаки занятости (справа от регистров, строки 6–13)**

* **Фиксирующие триггеры q0–q7 (J6:J13):** признак занятости регистра r
* **Принимающие триггеры Q0–Q7 (K6:K13):** признак занятости регистра R

**5. Сигналы-признаки состояния (справа)**

* **Признак заполненности З (M7):** равен состоянию триггера Q7.
* **Признак пустоты П (M11):** проверяет диапазон K6:K13 через функцию ИЛИ и выдает 1 только тогда, когда все триггеры Q равны нулю.
